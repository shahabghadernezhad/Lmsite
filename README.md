# SecureVision Demo — نسخه‌ی نمایشی قابل اجرا

این یک نسخه‌ی **کامل و واقعاً قابل اجرا** از داشبورد پلتفرم امنیتی SecureVision است:
فرانت‌اند + بک‌اند (API) + دیتابیس، همه در یک پروژه‌ی Node.js ساده.

> ⚠️ توجه: این یک **دمو** برای نمایش معماری و رابط کاربری است، نه محصول نهایی صنعتی.
> اتصال واقعی به دوربین (RTSP/ONVIF)، مدل‌های AI واقعی (YOLO، تشخیص چهره) و اجرای
> روی سخت‌افزار Edge (مثل Jetson) در این نسخه پیاده‌سازی نشده و نیاز به کار توسعه‌ی
> جداگانه دارد. داده‌ها نمونه (Mock) هستند اما تمام رفتار سیستم — API، دیتابیس،
> احراز هویت، فیلترها، قوانین خودکار — واقعی و کاربردی است.

## پیش‌نیاز

فقط **Node.js نسخه‌ی ۱۸ یا بالاتر** لازم است. چیز دیگری (Docker، PostgreSQL، و…) نیاز نیست.

بررسی نسخه:
```bash
node -v
```
اگر نصب نیست، از https://nodejs.org دانلود کنید.

## نصب و اجرا

```bash
# ۱. وارد پوشه‌ی پروژه شوید
cd securevision-demo

# ۲. وابستگی‌ها را نصب کنید (فقط یک‌بار)
npm install

# ۳. سرور را اجرا کنید
npm start
```

سپس در مرورگر بروید به:
```
http://localhost:3000
```

## چه چیزی در این دمو کار می‌کند؟

- **داشبورد زنده**: آمار دستگاه‌ها، رویدادهای امروز، هشدارهای بحرانی، نمودار رویداد به تفکیک ساعت و شدت
- **مدیریت دستگاه‌ها**: افزودن/حذف دوربین، کنترلر درب، سنسور — فیلتر بر اساس سایت و نوع
- **رویدادها**: لیست رویدادهای امنیتی با فیلتر شدت/وضعیت، دکمه‌ی «شبیه‌سازی رویداد جدید» برای دیدن رفتار Real-time، امکان علامت‌گذاری «رسیدگی‌شده»
- **موتور قوانین خودکار (Rule Engine)**: تعریف قوانین IF/THEN، فعال/غیرفعال کردن با یک کلیک
- **مدیریت کاربران**: افزودن/حذف کاربر با نقش‌های مختلف (فقط مدیر سیستم)
- **شبیه‌سازی حالت Offline-First**: دکمه‌ی «شبیه‌سازی قطعی اینترنت» در سایدبار وضعیت
  آنلاین/آفلاین سیستم را تغییر می‌دهد تا رفتار مدنظر معماری (کارکرد محلی بدون اینترنت) نمایش داده شود

## ساختار پروژه

```
securevision-demo/
├── server.js        ← بک‌اند Express (تمام API ها)
├── db.js             ← لایه‌ی دیتابیس (فایل JSON محلی، بدون نیاز به نصب دیتابیس)
├── data/db.json       ← فایل دیتابیس (به‌صورت خودکار در اولین اجرا ساخته می‌شود)
├── public/
│   ├── index.html    ← رابط کاربری (SPA)
│   ├── style.css      ← استایل (تم تیره‌ی مرکز عملیات امنیتی)
│   └── js/app.js      ← منطق فرانت‌اند (fetch به API، بدون فریم‌ورک)
└── package.json
```

## بازنشانی داده‌ها

اگر می‌خواهید داده‌ها به حالت اولیه برگردند، کافیست فایل `data/db.json` را حذف کنید
و سرور را دوباره اجرا کنید — داده‌های نمونه از نو ساخته می‌شوند.

```bash
rm data/db.json
npm start
```

## مراحل بعدی برای تبدیل به محصول واقعی

این دمو پایه‌ی خوبی برای شروع است، اما برای نسخه‌ی صنعتی طبق معماری Offline-First
که پیش‌تر طراحی شد، مراحل بعدی شامل موارد زیر است:

1. جایگزینی دیتابیس JSON با SQLite/PostgreSQL واقعی + Sync Engine
2. اتصال واقعی دوربین‌ها از طریق RTSP/ONVIF
3. اجرای مدل‌های AI واقعی (YOLOv8 و غیره) روی Edge
4. پیاده‌سازی صف رویداد آفلاین و منطق Retry/Conflict Resolution
5. سیستم لایسنس Hybrid (JWT + Hardware Fingerprint)
6. استقرار روی سخت‌افزار Edge (Jetson / Mini PC) با Docker

اگر بخواهید، می‌توانیم هرکدام از این مراحل را جداگانه پیش ببریم.
